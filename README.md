# Nane Benites Style

Crie um website extremamente profissional, sofisticado, moderno e minimalista para uma marca de moda fitness feminina chamada:

NANE BENITES MODA FITNESS

O objetivo principal do site é transmitir autoridade, elegância e desejo, gerando contatos pelo WhatsApp.

O site deve parecer uma marca premium, semelhante a Nike, Alo Yoga, Lululemon, Adidas, Gymshark e Lança Perfume, porém mantendo identidade própria.
